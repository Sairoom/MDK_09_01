# Макеты интерфейса

Предложенная авторская концепция: moodboard.svg и design-system.html. desktop и mobile содержат отдельные HTML-файлы семи страниц. Открывать index.html внутри выбранной папки; мобильные макеты проверяются при 390×844. Это статические демонстрационные снимки шаблонов с отключённой отправкой форм. Для регистрации и действий с БД запустите приложение из корневого README.
