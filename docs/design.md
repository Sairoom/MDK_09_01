# Требования и концепция дизайна

Портал предназначен для студентов, начинающих специалистов и организаторов профессиональных событий. Участник должен быстро выбрать событие и понять, принят ли он. Организатору нужны различимые статусы и предсказуемая смена состояния. В исходном задании не предоставлен брендбук, поэтому для учебного проекта предложен собственный стиль «Конференции.РФ». Согласование с реальным заказчиком не проводилось.

## Страницы

| Страница | Основное действие | Обязательные состояния |
|---|---|---|
| Каталог | Выбрать событие | Карточки событий, переход к заявке |
| Регистрация | Создать аккаунт | Пустая форма, ошибка полей, занятый логин |
| Авторизация | Войти | Ошибка данных, успешный переход в кабинет |
| Мои заявки | Проверить статус | Пустой список, новая, назначенная, завершённая |
| Новая заявка | Отправить заявку | Выпадающие списки, ошибка, успешная отправка |
| Панель администратора | Обработать заявки | Счётчики, фильтр, карточки, пустой фильтр |
| Личный кабинет | Проверить свои данные | Логин, email, телефон, роль |
| Отзыв | Оценить завершённое событие | Оценка 1–5, длина текста, сохранённый отзыв |

## Визуальная система

Мудборд: спокойная редакционная типографика, круги как символ обмена идеями, светлая бумага, крупные номера событий, карточки с открытыми полями. Векторные круги и знак ↗ заменяют тяжёлые растровые обложки; внешние изображения, шрифты и трекеры отсутствуют.

| Токен | Значение | Назначение |
|---|---|---|
| ink | #172C24 | Основной текст |
| green | #245B44 | Кнопки, ссылки, акценты |
| lime | #E3F397 | Светлый акцент на тёмном фоне |
| paper | #F7F8F2 | Фон страницы |
| muted | #62726A | Вторичный текст |
| line | #DCE3D9 | Границы и разделители |

Шрифтовая пара: Georgia для крупных заголовков, Segoe UI с запасным Arial для интерфейса. Используются системные шрифты: дополнительных сетевых запросов нет. Для ошибок кроме цвета служат текст и атрибут aria-invalid; статусы подписаны словами.

## Адаптация и взаимодействие

На широком экране каталог имеет три колонки, список заявок — две, формы — две смысловые области. При ширине до 700 px сетки становятся одноколоночными, меню переносится, боковой декоративный знак в формах скрывается. На 390×844 сохраняются поля по 18 px, элементы формы шириной 100%, кнопки высотой около 48 px. Макеты для мобильного просмотра сохранены отдельными HTML-файлами в design/mobile.

Переход содержимого длится 280 мс, hover кнопок — 160 мс, карточек — 200 мс. Анимируются transform и opacity, раскладка страницы не пересчитывается на каждом кадре. При prefers-reduced-motion все анимации и плавная прокрутка отключаются. Валидация появляется непосредственно под полями, фокус переводится в первое неверное поле, содержимое обычных полей сохраняется сервером после ошибки. Пароль повторно в HTML не выводится.

Источники визуальной концепции — собственная векторная композиция и правила, зафиксированные в этом документе; moodboard.svg и design-system.html позволяют проверить выбранные цвета и типографику. Статические макеты в design/desktop показывают страницы, фактическое взаимодействие реализовано в app/templates и app/static/app.js.
