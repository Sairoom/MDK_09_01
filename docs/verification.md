# Проверка выбранных практик

В комплект входят № 1, 2, 6, 7, 12 и 13: по две работы из диапазонов 1–5, 6–9 и 10–16.

Для практик 1 и 6 подготовлены документы с требованиями. Для практик 2 и 12 — ER-диаграммы, словарь данных, схема MySQL и миграция v1 → v2 с сохранением существующих заявок. Для практик 7 и 13 — мудборд, цвета, шрифты, HTML-макеты и адаптивные страницы общего приложения.

Серверный набор tests/test_portal.py проверяет в том числе перенос завершённой заявки из старой схемы, повторную миграцию и целостность внешних ключей. Результат предыдущего локального прогона: 22 теста прошли; журнал — evidence/unit-tests.txt. Набор также запускается с MySQL 8.4 через GitHub Actions.

В браузере проверены страницы на ширине 390 px: горизонтального переполнения нет. Условия и результаты Chromium находятся в evidence/results.json, Firefox и отдельных HTML-макетов — в evidence/crossbrowser.json. Использовалась эмуляция 390×844, физический смартфон не использовался. Скриншоты показывают запущенное приложение.

Для каждой из шести работ сохранён отдельный отчёт Word с исходным титульником и заменённой темой. Отчёты проверены после рендеринга, каждый занимает три страницы.
