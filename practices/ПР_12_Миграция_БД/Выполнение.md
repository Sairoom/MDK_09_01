# Практическая работа № 12

## Доработка структуры БД

Цель: Добавить справочник статусов и отзывы с переносом существующих данных.

## Выполнение

1. Зафиксирована исходная схема v1 с пользователями, мероприятиями и заявками.

2. В версии v2 добавлены statuses, reviews и внешний ключ applications.status_id.

3. Строковые статусы старых записей преобразуются в идентификаторы 1, 2 и 3.

4. Созданы индексы для статуса и даты; обновлена ER-диаграмма и SQL для MySQL.

5. Проверены перенос записи без изменения id, повторяемость миграции и отсутствие нарушенных внешних ключей.

## Результат и проверка

Регрессионный тест переносит завершённую заявку из v1 в v2. Повтор миграции не дублирует таблицы и записи справочника.
