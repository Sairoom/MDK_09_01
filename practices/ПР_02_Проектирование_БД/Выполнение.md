# Практическая работа № 2

## Проектирование базы данных ER диаграмма

Цель: Спроектировать сущности портала и определить связи между ними.

## Выполнение

1. Выделены пользователи, мероприятия, заявки, справочник статусов и отзывы.

2. Для каждой сущности заданы типы, обязательность и первичный ключ; логин и email уникальны.

3. Заявка связывает пользователя и мероприятие, реализуя M:N; повтор пары user_id и event_id запрещён.

4. У заявки может быть не более одного отзыва; статус выбирается из справочника.

5. Построены редактируемая SVG-диаграмма, её PNG и словарь данных; добавлен SQL для MySQL 8.4.

## Результат и проверка

Диаграмма содержит пять предметных сущностей, кардинальности и ключи. Внешние ключи проверены серверными тестами.

Файлы: db/dictionary.md, db/er.svg, db/schema.mysql.sql
